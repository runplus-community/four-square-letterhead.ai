# FSL Pack v1.1

Current canonical **Four-Square Letterhead (FSL)** file-backed pack.

## Identity rule
Each generated page tracks two versions separately:
- project/sample version, e.g. **Django Sample v1.1**
- template version, **Four-Square Template v1.1**

## Included
- 1P / 2P / 3P reusable templates
- Django illustrative 2-page sample
- FSL v1.1 skill
- FSL v1.1 memory/recall file
- FSL v1.1 manifest

`SPEC` and `MEMORY` are fixed lanes. The two middle lanes are project-defined and remain stable across versions.
