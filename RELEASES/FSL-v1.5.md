# FSL v1.5 — Compact Working Letterhead

FSL v1.5 simplifies the v1.4 development model while keeping its traceability and proof guardrails.

## Highlights

- one initial development sequence instead of mandatory per-iteration declarations
- no YAML iteration schema, no full future-iteration plan, no iteration ledger requirement
- E2E / parallel E2E / E2M / M2E / midpoint approaches remain available as lightweight guidance
- component and partial-path evidence MUST NOT be represented as integrated E2E proof
- essential references reduced to `ITEM | INTENT / USE | CANONICAL SOURCE`
- SPEC and MEMORY remain fixed; middle lanes remain project-defined
- every rendered page carries: **FSL owns the method. The project owns the work.**
- 1P / 2P / 3P templates and Django 2P illustrative sample regenerated and CI-validated
