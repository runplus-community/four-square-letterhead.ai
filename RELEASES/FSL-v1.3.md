# FSL v1.3 — Traceable Constitutional Letterhead

FSL v1.3 keeps the v1.2 constitutional vocabulary and 1–3 page limit, then adds a deliberately small machine-operability layer.

## Highlights
- stable material clause IDs using `FORM-SCOPE-NNN`
- scoped proof tuple: `CLAIM / SCOPE / ENVIRONMENT / EVIDENCE / RESULT`
- exact Four-Square reviewed-commit snapshot
- permanent separation of FSL/template version from governed project version
- explicit REUSE / INHERIT / REFERENCE semantics
- authority axiom: **MEMORY may remember law; MEMORY cannot make law**
- AI ambiguity rule: agents MUST NOT silently choose a stronger or weaker normative interpretation
- no new constitutional form categories
- 1P / 2P / 3P templates and Django v1.3 illustrative sample
