# FSL v1.2 — Constitutional Letterhead

FSL v1.2 evolves the Four-Square Letterhead into a compact constitutional project contract while preserving the file-backed model and 1–3 page maximum.

## Highlights
- explicit MUST / MUST NOT / SHOULD / SHOULD NOT / MAY semantics
- CAPITAL + bold + underline normative emphasis in rendered documents
- ARTICLE / LAW / CONTRACT / POLICY / GUARDRAIL / RECOMMENDED PRACTICE / CHECKLIST forms
- conformance states: CONFORMANT / CONFORMANT WITH EXCEPTION / NON-CONFORMANT / NOT YET PROVEN
- exception / waiver protocol
- checklist-driven development guidance
- defined agent authority boundaries
- amendment / change-control rules
- 1P / 2P / 3P templates
- Django v1.2 illustrative sample
- visible Four-Square Template v1.2 identity on every page

## Four-Square lanes
`spec-v1.2 | templates-v1.2 | skill-v1.2 | memory-v1.2`

Each lane continues from its corresponding v1.1 lane. `main` records accepted integration.

## Release rule
One version, four squares, all green. Binding violations MUST NOT be hidden; missing proof is NOT YET PROVEN.
