# Four-Square Letterhead v1.9

Theme: **Document Authority, Stewardship & Continuity**.

Core alignment: **Documents govern. Skills maintain. Evidence verifies.**

FSL v1.9 treats adopted project FSL documents as the source of truth for agreed business and technical intent. The maintenance skill keeps those documents aligned with work, evidence and decisions; it cannot silently change them.

Key additions include named stewardship and decision authority, drift/uncertainty handling, successor handover, one-or-many repository coordination, focused iterations and stable routes, and GitHub Actions OFF by default with explicit scoped approval and bounded call budgets when external automation is justified.

This is a public branch-scoped release on `release/fsl-v1.9`. Earlier release branches remain unchanged.

The branch publishes the authoritative text sources and exact Git snapshot. The downloadable distribution pack also contains locally generated and visually reviewed PDF/DOCX reading copies. No GitHub Actions were started to build or publish v1.9.
