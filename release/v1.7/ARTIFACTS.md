# FSL v1.7 artifact index

Start with FSL-v1.7-Template-1P.pdf and its editable DOCX. Use the 2P/3P forms only when essential route/adoption or lifecycle/release detail requires them. FSL-v1.7-Sample-Django-2P is an illustrative existing-system example with runtime NOT RUN.

The root includes Constitution, Routes (with blank run sheet), Adoption, Lifecycle, Skill, four-item Checklist, Memory, Changelog, Snapshot and Validation. The source folder carries the standalone generator and verifier. Manifest/checksums identify every payload file.

The branch directory also carries the distribution ZIP, its checksum and an external assembly run record. Those distribution/evidence wrappers are intentionally outside the ZIP payload so they do not hash or claim their own future publication.

FSL owns the method. The project owns the work.
