# FSL v1.1 branch release

Canonical branch-scoped release snapshot for Four-Square Letterhead (FSL) v1.1.

- Branch: `release/fsl-v1.1`
- Template identity: **Four-Square Template v1.1**
- Artifact directory: `release/v1.1/`
- Build: `.github/workflows/build-fsl-v1.1.yml`
- Reproducible source: `tools/build_fsl_v1_1.py`

The directory contains the actual 1P/2P/3P DOCX+PDF templates, Django 2P DOCX+PDF sample, skill, memory, manifest, ZIP package and checksums. The workflow builds and validates the document artifacts before committing them back to this branch.

This is a branch-based release snapshot, not a GitHub Releases-page asset set. Because the repository is public, this branch is also publicly readable.
