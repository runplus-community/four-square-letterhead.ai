# FSL Memory - v1.3

**FSL = Four-Square Letterhead. Canonical development version: v1.3.**

## File-backed recall
When FSL is recalled, retrieve/use the actual v1.3 files first, not theory alone. Canonical set includes 1P/2P/3P DOCX+PDF templates, Django v1.3 sample, Constitution, Skill, Checklist, Iterations CSV, Traceability Guide, Snapshot example, Manifest, README and checksums.

## Fixed model
SPEC and MEMORY are fixed. Two middle lanes are project-defined and version-stable unless a reviewed migration changes them. `main1` is immutable first-commit root; `main` is accepted integration.

## v1.3 traceability
Material binding clauses have stable `FORM-SCOPE-NNN` IDs. Proof tuple: CLAIM / SCOPE / ENVIRONMENT / EVIDENCE / RESULT. Accepted releases record the exact four reviewed commits; Git remains authoritative.

## Version identity
`Four-Square Template v1.3` identifies FSL governance language. Project/contract/sample version identifies the governed system. They are separate.

## Iteration development
FSL develops through small ordered end-to-end iterations.

Every iteration closes one useful requirement from requirement to implementation to usable state to checker to evidence. `Implemented` alone is not complete.

**ITERATE -> TOUCH -> PROVE -> LEARN -> INCREMENT**

Use one short sequence CSV:

`Seq,Iteration,Requirement,Touchpoints,E2E Path,Proof,Status`

Statuses: `PLANNED | ACTIVE | PROVEN | BLOCKED`.

Seed only a few kickoff iterations. Add later rows as earlier iterations become PROVEN and learning improves the next decision. Do not pre-plan the entire final system just to fill the CSV.

Touchpoints are system surfaces, not branches. Relevant touchpoints are still inspected as `CHANGE | VERIFY | NOT AFFECTED`, but the CSV may list only the concise touchpoint names.

**Branches say who owns responsibility. Touchpoints say where an iteration crosses the system.**

## Reuse semantics
REUSE = use proven capability without automatically importing source law. INHERIT = explicitly adopt a requirement/contract. REFERENCE = use knowledge/evidence without adopting its authority.

## Authority axioms
**MEMORY may remember law; MEMORY cannot make law.**

Agents MUST NOT invent missing law or silently choose the stronger/weaker interpretation when normative intent is ambiguous.

## Page depth
1 page simple, 2 pages medium, 3 pages maximum. Supporting artifacts hold detail that would otherwise bloat FSL.
