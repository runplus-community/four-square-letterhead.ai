## v1.4 development strategy
Every material iteration declares:

`STRATEGY / TOUCHPOINT SET / START-MIDPOINT-END (as applicable) / EXPECTED EVIDENCE / EXIT CONDITION`

Canonical strategies:
- E2E
- E2M
- M2E
- PARALLEL E2E
- MEET-IN-THE-MIDDLE
- INCREMENTAL E2E

Every declared touchpoint is exercised meaningfully for the claimed path. Tiny implementation at a touchpoint is acceptable when it proves the path. A component test is not E2E proof. A declared touchpoint cannot be silently bypassed in an E2E claim.

Development axiom: **TOUCH EVERYTHING REQUIRED; COMPLETE LITTLE; GROW WHAT IS PROVEN.**
