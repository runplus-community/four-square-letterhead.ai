## Routes and proof

R-01 = stable project-scoped route, not iteration number. Show input -> every required touchpoint -> observable output, with expected outcome and baseline. Each run repeats the full declared list, records PASS / FAIL / NOT RUN and exact evidence/context. A run may fail; a route label is not proof. Partial, skipped or stubbed coverage cannot be promoted to a wider E2E claim. Do not reuse historic PASS automatically.

## Lifecycle

Before first release, reviewed draft SPEC can change. Appendix supports study/development; errata corrects without changing intent; an adopted amendment changes released intent. A committed proposal is not adopted law. Record authority, exact delta, base clauses/version and effective scope. Reassess affected routes. Preserve old baselines; incorporate applicable adopted changes into the next clean release.
